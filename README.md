
# Experiment 4: Healthy Living Website

## Aim
To optimize a webpage for SEO and accessibility using semantic HTML, proper heading structure and meta tags.

## Technologies Used
- HTML5
- CSS3

## Features
1. Semantic HTML elements.
2. Proper heading hierarchy.
3. SEO-friendly title and meta description.
4. Accessible navigation.
5. Form labels and accessibility attributes.
6. Responsive webpage layout.
7. Keyboard-friendly navigation.

## Files
- index.html - Structure and content of the webpage.
- style.css - Styling and responsive layout.

## How to Run
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.

## Conclusion
Successfully developed an SEO-friendly and accessible webpage using HTML5 and CSS3.
